## 2. 一般牌全表

| id | 名称 | 效果 | 目标 | 张数 |
|---|---|---|---|---|
| `atk` | 攻 | 触发英雄**普攻**（用英雄的攻击类型 + 伤害） | 单体（按英雄攻击类型） | 16 |
| `skill1` | 技1 | 触发英雄**技能 1** | 由技能定义 | 8 |
| `skill2` | 技2 | 触发英雄**技能 2** | 由技能定义 | 8 |

> **核心机制**：`技1/技2/大` 是**触发牌**——打出即激活**自己英雄**的对应技能（同一张牌在不同英雄手里效果不同）。

## 3. 道具牌框架

```ts
interface ItemCardDef extends CardDef {
  kind: 'item';
  subtype: 'plain' | 'passive' | 'placement';
}
```

| 子类 | 能否主动打出 | 触发方式 | 生命周期 |
|---|---|---|---|
| **一般** `plain` | ✅ | 打出即结算 | 进弃牌堆 |
| **被动** `passive` | ❌ | 满足条件自动触发；也可主动弃掉 | 触发/弃掉后进弃牌堆 |
| **放置** `placement` | ✅ | 打出后落到地图格 | 成为 `PlacedObject`，到期移除 |

### 3.1 首批示例条目（占位，待用户定稿）

| id | 名称 | 子类 | 效果 |
|---|---|---|---|
| `item_bomb` | 落雷符 | 一般 | 目标格及其 4 邻各受 3 法术伤害 |
| `item_thorn` | 荆棘缠绕 | 放置 | 在目标格放置陷阱，敌人踩上 → 定身 1 回合 |
| `item_shieldcharm` | 护身符 | 被动 | 首次受到致命伤害时免疫，保留 1 HP，然后弃掉 |
| `item_spring` | 涌泉 | 放置 | 目标格变回血点，持续 3 回合 |

## 4. 特殊卡牌属性 / 功能脑暴（**24 条**）

全部实现为 `EffectOp` 或 `Modifier`，可作为**卡牌效果**或**英雄特殊属性**复用。

| # | 名称 | 归类 | 效果 |
|---|---|---|---|
| 1 | **穿刺** | 攻击 | 本次攻击无视目标护盾 |
| 2 | **溅射** | 攻击 | 对目标相邻格单位造成 50% 伤害 |
| 3 | **吸血** | 攻击 | 造成伤害的 50% 转化为自身 HP |
| 4 | **破墙** | 攻击 | 攻击沿途摧毁遇到的墙（远程弹道清障） |
| 5 | **缴械** | 控制 | 目标下回合不能出牌 |
| 6 | **定身** | 控制 | 目标下回合不能移动 |
| 7 | **沉默** | 控制 | 目标不能使用法术类技能/牌 |
| 8 | **灼烧** | DoT | 目标每回合开始受 1 伤害，持续 N 回合 |
| 9 | **剧毒** | DoT | 每回合受伤害并可叠加层数（层数 = 伤害） |
| 10 | **护盾** | 防御 | 吸收 N 点**普通**伤害后破碎 |
| 11 | **魔抗罩** | 防御 | 吸收 N 点**法术**伤害后破碎 |
| 12 | **反弹** | 防御 | 受伤时对攻击者反弹 50% 伤害 |
| 13 | **换位** | 位移 | 与目标**交换位置** |
| 14 | **推挤** | 位移 | 把目标沿直线后推 2 格（遇障碍停） |
| 15 | **拉拽** | 位移 | 把目标拉到自己身边（相邻格） |
| 16 | **传送** | 位移 | 瞬移到地图上任一可站格 |
| 17 | **抽牌** | 资源 | 立即从共享牌堆抽 2 张 |
| 18 | **弃牌** | 资源 | 目标随机弃 1 张手牌 |
| 19 | **偷牌** | 资源 | 偷取目标 1 张手牌（进自己手牌） |
| 20 | **续行** | 机动 | 本回合额外获得 2 格移动预算 |
| 21 | **额外回合** | 机动 | 立刻再行动一次（不换人） |
| 22 | **召唤** | 召唤 | 在相邻空格召唤一个哨兵单位 |
| 23 | **陷阱** | 放置 | 在目标格放置减速物（踩上本回合只能走 0 格） |
| 24 | **落石** | 地形 | 目标格及相邻格变为墙，持续 1 回合 |

### 4.1 可作为英雄特殊属性的 `Modifier`（额外补充）

| 名称 | 效果 |
|---|---|
| **穿墙** | 移动无视墙（但仍不可停在墙内） |
| **起手多抽** | 开局手牌 +N 张 |
| **法术减伤** | 受到法术伤害 −X |
| **普攻强化** | 普攻伤害 +X |
| **疾行** | 每回合移动格数 +N |
| **不死之身** | 每局首次死亡免疫（保留 1 HP） |
| **免疫定身** | 不受定身/缴械影响 |

> 以上清单可继续扩充；英雄与卡牌只需引用这些算子/修饰符即可，**引擎不改**。
